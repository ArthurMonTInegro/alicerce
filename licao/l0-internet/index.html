Conceito Concept

Ao final desta lição você vai conseguir:

  • Explicar o modelo cliente-servidor

  • Entender IP, DNS e portas em alto nível

  • Descrever o caminho de uma requisição HTTP do navegador ao servidor

A internet é uma rede de redes: bilhões de dispositivos que trocam mensagens seguindo regras comuns, os protocolos. A maior parte da web funciona no modelo clienteclient–servidorserver: o cliente pede, o servidor responde.
