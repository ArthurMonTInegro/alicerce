Conceito Concept

Ao final desta lição você vai conseguir:

  • Aplicar princípios de legibilidade

  • Reconhecer code smells

  • Refatorar com segurança, apoiado em testes

  • Fazer e receber code review

Código é lido muito mais vezes do que é escrito. Código limpo é código que outra pessoa (ou você daqui a 6 meses) entende rápido e muda com segurança. Refatorar é melhorar a estrutura sem mudar o comportamento — e os testes são o que garante que nada mudou.
