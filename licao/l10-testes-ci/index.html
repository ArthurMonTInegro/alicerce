Conceito Concept

Ao final desta lição você vai conseguir:

  • Distinguir testes de unidade, integração e ponta a ponta

  • Usar test doubles (mocks, stubs, fakes)

  • Entender o que é um pipeline de CI

  • Interpretar cobertura com senso crítico

Em um projeto real, os testes formam uma pirâmide: muitos testes de unidade (rápidos, isolados), alguns de integração e poucos ponta a ponta (lentos, frágeis, mas próximos do usuário). A integração contínua roda tudo automaticamente a cada push, para que nenhum erro chegue à branch principal.
