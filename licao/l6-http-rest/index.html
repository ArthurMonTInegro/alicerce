Conceito Concept

Ao final desta lição você vai conseguir:

  • Usar corretamente métodos e códigos de status HTTP

  • Projetar rotas REST para um recurso

  • Serializar e validar JSON

  • Entender idempotência, cache e CORS em alto nível

Uma APIAPI web é um servidor que responde a requisições HTTP com dados (geralmente JSON) em vez de páginas. REST é um estilo de projeto em que a URL identifica um recursoresource e o método HTTP diz o que fazer com ele.
