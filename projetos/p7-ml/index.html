Projeto 7 · Avançado

Classificador do zero Classifier from scratch

Implementa k-NN, regressão logística e uma rede neural pequena do zero, compara com bibliotecas e escreve um relatório honesto.

Requisitos

  • Separar treino, validação e teste sem vazamento de dados.
  • Implementar k-NN e regressão logística sem bibliotecas de ML.
  • Rede com uma camada escondida em NumPy (forward, loss, backprop).
  • Comparar acurácia, precisão, revocação e matriz de confusão.
  • Relatório com limitações, vieses possíveis e o que não se pode concluir.

Etapas

Critérios de aceite

Seu projeto está pronto quando tudo isto for verdade (e, idealmente, verificado por testes):

  • O conjunto de teste é usado uma única vez, no fim.
  • Os resultados são reprodutíveis (semente fixa, versões anotadas).
  • O relatório compara com a baseline.

Para ir além

  • Curva de aprendizado (tamanho do treino × erro).
  • Ficha do modelo (model card).

Pré-requisitos e habilidades

Módulos: Fundamentos de machine learning

  • Machine learning
  • Redes neurais
  • Combinatória e probabilidade

Inglês do projeto

  • linha de base→baseline

    Resultado mínimo de referência, de um método trivial.

  • vazamento de dados→data leakage

    Informação do teste que contamina o treino e infla o resultado.

  • sobreajuste→overfitting

    Modelo que decora o treino e generaliza mal.

Como entregar

Crie um repositório público no GitHub para o projeto, com README (o que é, como rodar, como testar, decisões), commits pequenos e frequentes e, a partir do Projeto 2, testes automatizados. Veja o guia de carreira para transformar o projeto em vitrine.
