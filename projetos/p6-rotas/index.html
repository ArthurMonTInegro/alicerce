Projeto 6 · Avançado

Planejador de rotas Route planner

Lê um mapa de cidades e estradas, encontra o menor caminho e compara algoritmos com medições reais.

Requisitos

  • Carregar um grafo ponderado de um CSV (origem, destino, distância).
  • BFS para menor número de trechos e Dijkstra (com heapq) para menor distância.
  • Reconstruir e mostrar o caminho, não só o custo.
  • Detectar cidades inalcançáveis e entrada inválida (peso negativo).
  • Medir tempo de execução em grafos de 100, 1.000 e 10.000 vértices e comparar com a análise Big O.

Etapas

Critérios de aceite

Seu projeto está pronto quando tudo isto for verdade (e, idealmente, verificado por testes):

  • Resultados de Dijkstra batem com uma implementação de força bruta em 100 grafos aleatórios pequenos (teste de propriedade).
  • O README explica por que Dijkstra não funciona com pesos negativos.

Para ir além

  • A* com heurística de distância em linha reta.
  • Bellman-Ford para pesos negativos.
  • Visualização do caminho em SVG.

Inglês do projeto

  • menor caminho→shortest path

    Caminho de custo total mínimo entre dois vértices.

  • fila de prioridade→priority queue

    Estrutura que sempre entrega o menor (ou maior) elemento primeiro.

  • teste baseado em propriedades→property-based testing

    Testar uma regra geral com muitas entradas geradas.

Como entregar

Crie um repositório público no GitHub para o projeto, com README (o que é, como rodar, como testar, decisões), commits pequenos e frequentes e, a partir do Projeto 2, testes automatizados. Veja o guia de carreira para transformar o projeto em vitrine.
