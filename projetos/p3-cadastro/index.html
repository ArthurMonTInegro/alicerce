Projeto 3 · Intermediário

Sistema de cadastro acadêmico Student records system

Cadastro de alunos que evolui de dict em memória para objetos, camadas, SQLite com relacionamentos, índices e transações.

Requisitos

  • Buscar aluno por matrícula em O(1) e por nome (parcial, sem diferenciar maiúsculas).
  • Modelar Aluno, Professor e Disciplina com classes; Cadastro encapsula o armazenamento.
  • Exportar para CSV e JSON via interface Exportador (composição).
  • Persistir em SQLite com consultas parametrizadas.
  • Matrículas N:N e boletim do aluno com JOIN.
  • Esquema na 3FN, índices justificados e matrícula múltipla em uma transação.

Etapas

Critérios de aceite

Seu projeto está pronto quando tudo isto for verdade (e, idealmente, verificado por testes):

  • Trocar JSON por SQLite não muda nenhuma linha fora do módulo de armazenamento.
  • Nenhuma consulta monta SQL com f-string ou concatenação.
  • Uma matrícula que falha no meio não deixa dados parciais (rollback).
  • Testes usam banco :memory: e rodam em menos de 1 segundo.

Para ir além

  • Importação de CSV com relatório de linhas rejeitadas.
  • Migrações versionadas do esquema.
  • Interface web simples (depois do Nível 6).

Pré-requisitos e habilidades

Módulos: Tabelas hash e conjuntos

  • Tabelas hash
  • Algoritmos de busca
  • Classes, objetos e encapsulamento
  • Herança, polimorfismo e composição
  • SQL
  • Relacionamentos e JOINs
  • Modelagem, índices e transações

Inglês do projeto

  • camada de acesso a dados→data access layer

    Parte do código que conversa com o banco; o resto não sabe qual banco é.

  • consulta parametrizada→parameterized query

    SQL com marcadores (?) preenchidos pelo driver, que impede SQL injection.

  • reverter→rollback

    Desfazer todas as operações de uma transação.

Como entregar

Crie um repositório público no GitHub para o projeto, com README (o que é, como rodar, como testar, decisões), commits pequenos e frequentes e, a partir do Projeto 2, testes automatizados. Veja o guia de carreira para transformar o projeto em vitrine.
