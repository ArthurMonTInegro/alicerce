Projeto 8 · Avançado

Chat em rede com servidor concorrente Networked chat with a concurrent server

Servidor de chat com sockets TCP que atende vários clientes ao mesmo tempo, com um protocolo de texto definido por você.

Requisitos

  • Servidor TCP com asyncio (ou threads) atendendo vários clientes.
  • Protocolo documentado: mensagens delimitadas por linha, comandos /nick, /sala, /sair.
  • Tratar desconexão abrupta sem derrubar o servidor.
  • Estado compartilhado (salas e usuários) sem condições de corrida.
  • Testes de integração que abrem vários clientes de verdade.

Etapas

Critérios de aceite

Seu projeto está pronto quando tudo isto for verdade (e, idealmente, verificado por testes):

  • 50 clientes simultâneos em teste automatizado sem perda de mensagens.
  • Mensagem maior que o limite é recusada com erro do protocolo, sem travar.

Para ir além

  • TLS com certificado autoassinado.
  • Cliente web via WebSocket.

Pré-requisitos e habilidades

Módulos: Concorrência e sincronização, Camadas, IP, TCP e UDP

  • TCP/IP
  • Programação com sockets
  • Concorrência e sincronização
  • Processos e escalonamento

Inglês do projeto

  • soquete→socket

    Ponto de comunicação entre processos pela rede.

  • condição de corrida→race condition

    Resultado que depende da ordem imprevisível de execução.

  • protocolo→protocol

    Regras de formato e ordem das mensagens.

Como entregar

Crie um repositório público no GitHub para o projeto, com README (o que é, como rodar, como testar, decisões), commits pequenos e frequentes e, a partir do Projeto 2, testes automatizados. Veja o guia de carreira para transformar o projeto em vitrine.
