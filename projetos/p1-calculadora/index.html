Projeto 1 · Iniciante

Calculadora no terminal Command-line calculator

Seu primeiro programa completo: lê números e uma operação, calcula, trata divisão por zero e repete até o usuário sair.

Requisitos

  • Ler dois números e uma operação (+, -, *, /, //, %, **) com input().
  • Converter a entrada para número e avisar quando ela não for numérica.
  • Tratar divisão por zero com uma mensagem clara, sem o programa quebrar.
  • Repetir até o usuário digitar "sair".
  • Organizar o cálculo em funções: somar, subtrair, multiplicar, dividir e calcular(a, op, b).

Etapas

Critérios de aceite

Seu projeto está pronto quando tudo isto for verdade (e, idealmente, verificado por testes):

  • calcular(6, "/", 3) devolve 2.0 e calcular(7, "//", 2) devolve 3.
  • Dividir por zero mostra uma mensagem e o programa continua.
  • Digitar texto no lugar de número não derruba o programa.
  • Nenhuma função imprime e calcula ao mesmo tempo (separação entre lógica e E/S).

Para ir além

  • Histórico das últimas 5 contas.
  • Aceitar a expressão inteira em uma linha, como "3 * 4".
  • Escrever 5 testes com assert para calcular().

    Dados digitados por quem usa o programa.

Como entregar

Crie um repositório público no GitHub para o projeto, com README (o que é, como rodar, como testar, decisões), commits pequenos e frequentes e, a partir do Projeto 2, testes automatizados. Veja o guia de carreira para transformar o projeto em vitrine.
