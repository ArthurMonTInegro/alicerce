Verificar minha base

Resolva quatro situações sem executar código nem consultar exemplos. Depois explique seu raciocínio e tente uma transferência.

Faça esta atividade depois de estudar o nível correspondente. É prática formativa, com ajuda autodeclarada, sem certificação nem aumento automático do indicador de domínio.

Rever os pré-requisitos deste nível

1. Representação

Um sensor usa 5 bits e reserva o padrão 00000 para erro. Quantos padrões sobram para medidas válidas? Responda com um inteiro.

2. Estado e persistência

Um editor mantém uma alteração apenas na RAM, sem salvamento automático. Uma queda de energia ocorre. A alteração está garantida no arquivo? Responda sim ou não.

3. Localizar a falha

Um cliente recebeu resposta HTTP 404 do servidor. Isso prova uma falha de resolução DNS nessa requisição? Responda sim ou não.

4. Aplicar caminhos

A pasta atual é /estudo/aulas. Qual caminho absoluto corresponde a ../dados/notas.txt?
