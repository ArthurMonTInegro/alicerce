Nível 5

Programação Orientada a Objetos Object-Oriented Programming

Modelar sistemas com objetos coesos e pouco acoplados, usando princípios e padrões com critério.

Por que este nível existe

A maior parte do software comercial (Java, C#, Python, TypeScript) é organizada com objetos. Entender POO de verdade — não só sintaxe de classe — é o que permite ler e evoluir sistemas grandes.
